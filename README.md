# 개선OPL

쿼터뷰 멀티플레이 슈팅 게임. 서버 한 대를 켜고 같은 네트워크의 친구들이 브라우저로 접속합니다.

## 실행

1. [Node.js](https://nodejs.org) 설치 (처음 한 번)
2. `개선OPL.bat` 더블클릭 → 처음엔 패키지를 설치하고, 서버가 켜지면 브라우저가 자동으로 열립니다
3. 친구들은 서버 창에 표시된 `같은 네트워크: http://192.168.x.x:7777` 주소로 접속

처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러야 다른 PC에서 접속할 수 있습니다.
포트를 바꾸려면 `set PORT=8080` 후 `node server.js`.

## 인터넷 배포 (Render 무료)

어디서든 접속할 수 있는 고정 주소를 만들려면:

1. 이 폴더를 GitHub 저장소에 올립니다 (비공개 저장소도 가능)
2. [render.com](https://render.com) 가입 → GitHub 계정 연결
3. **New → Blueprint** → 저장소 선택 → **Apply**
   (`render.yaml`에 설정이 들어 있어 따로 입력할 필요 없음)
4. 배포가 끝나면 나오는 `https://gaeseon-opl-xxxx.onrender.com` 주소를 공유

Blueprint 대신 **New → Web Service**로 만들 경우: Build Command `npm install`, Start Command `node server.js`, Instance Type **Free**.

- 이후 GitHub에 push할 때마다 자동으로 다시 배포됩니다.
- 무료 플랜은 15분간 접속이 없으면 잠들고, 다음 첫 접속 때 깨어나는 데 1분 정도 걸립니다.
- 서버가 재시작되면 점수판은 초기화됩니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 (화면 기준) |
| 마우스 | 조준 |
| 좌클릭 (누르고 있기) | 발사 |
| 1 / 2 / 3 | 인벤토리 무기 교체 |
| R | 재장전 |
| E | 인벤토리가 가득 찼을 때 바닥 무기와 현재 무기 교체 |
| 우클릭 (누르고 있기) | 조준 방향으로 멀리 보기 (저격소총은 더 멀리) |
| 마우스 휠 | 확대 / 축소 |
| Tab | 점수판 |
| Enter | 채팅 |

## 무기

| 무기 | 데미지 | 사거리 | 초당 발사 | 탄창 |
|---|---|---|---|---|
| 권총 (기본) | 20 | 16m | 3.3 | 12 / 무한 |
| 기관단총 | 11 | 12m | 11.8 | 30 |
| 산탄총 | 13 × 8발 | 7.5m | 1.2 | 6 |
| 돌격소총 | 22 | 22m | 8.3 | 25 |
| 저격소총 | 100 | 45m | 0.8 | 5 |

- 바닥의 무기를 밟으면 빈 칸에 자동으로 들어갑니다. 이미 있는 무기면 탄약이 보충됩니다.
- 발밑의 흰 원이 현재 무기의 사거리입니다. 조준점이 회색이면 사거리 밖입니다.
- 죽으면 들고 있던 무기를 떨어뜨리고 3초 뒤 권총만 들고 부활합니다.

## 맵

- **1층**: 들판, 상자/벽 엄폐물, 다리 아래 통로
- **2층**: 건물 3개의 옥상, 옥상을 잇는 다리, 감시탑 2개 (계단으로 올라감)
- 상자·벽 뒤에 숨으면 상대 화면에서 사라지고 총알도 막힙니다.
- 다른 층의 적은 마우스를 적 위에 올리면 높이까지 맞춰 조준됩니다. 옥상 가장자리에서는 아래를 쏠 수 있습니다.
- 건물 A/B 옥상 남쪽(북쪽) 난간이 뚫린 곳으로 뛰어내릴 수 있습니다.

## 파일 구성

- `server.js` — 게임 서버 (판정, 체력, 인벤토리, 아이템, 부활)
- `shared/common.js` — 맵, 무기 수치, 이동/충돌/사격 판정 (서버·클라이언트 공용)
- `public/` — 브라우저 클라이언트 (three.js 렌더링, HUD)

무기 수치나 맵은 `shared/common.js`에서 바로 고칠 수 있습니다.
