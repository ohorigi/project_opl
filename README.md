# 개선OPL

쿼터뷰 도트(픽셀아트) 멀티플레이 슈팅 게임. 서버 한 대를 켜고 친구들이 브라우저로 접속합니다.

- **PvP 대전**과 **PvE 스테이지**(1-1 ~ 1-5, 마지막에 개틀링을 든 보스) 중 골라서 입장
- 도트 미소녀 캐릭터 2종: 하루(세일러복), 레이(녹색 군복) — 앞·뒤·옆 3방향 걷기 애니메이션, 조준 방향을 바라봄
  (캐릭터·보스 그림은 Grok으로 만든 걷기 시트, 적 병사는 그 그림의 색을 바꾼 것)
- 화면 전체를 저해상도로 그린 뒤 또렷하게 확대하고 1픽셀 외곽선을 넣는 도트 렌더링,
  모든 표면 무늬(벽돌, 회벽, 마루, 판석, 잔디, 물, 상자, 드럼통 등)는 코드로 한 픽셀씩 그린 도트 텍스처
- 안으로 들어갈 수 있는 건물, 부서지는 상자·드럼통, 수류탄, 점프 기믹

## 실행

1. [Node.js](https://nodejs.org) 설치 (처음 한 번)
2. `개선OPL.bat` 더블클릭 → 처음엔 패키지를 설치하고, 서버가 켜지면 브라우저가 자동으로 열립니다
3. 친구들은 서버 창에 표시된 `같은 네트워크: http://192.168.x.x:7777` 주소로 접속

처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러야 다른 PC에서 접속할 수 있습니다.
포트를 바꾸려면 `set PORT=8080` 후 `node server.js`.

## 인터넷으로 같이 하기 (가입 없이)

`개선OPL-인터넷.bat`을 실행하면 서버와 함께 Cloudflare 임시 터널이 켜지고,
`https://아무글자.trycloudflare.com` 형태의 인터넷 주소가 만들어집니다.

- 주소는 서버 창에 표시되고 **클립보드에 자동 복사**됩니다. 메신저에 붙여넣어 보내면 끝.
- 서버를 켠 PC의 접속 화면(그리고 게임 중 Tab 점수판)에도 초대 주소가 나오며, 클릭하면 복사됩니다.
- 처음 실행 시 cloudflared가 없으면 자동으로 설치합니다 (Windows 권한 확인 창 → 예).
- 서버를 다시 켤 때마다 주소가 바뀝니다. 친구들은 설치할 것이 없습니다.
- 바깥에서 이 PC로 들어오는 통로를 여는 방식이므로 회사 PC·회사망에서는 쓰지 마세요.

## 인터넷 배포 (Render 무료)

어디서든 접속할 수 있는 고정 주소를 만들려면:

1. 이 폴더를 GitHub 저장소에 올립니다 (비공개 저장소도 가능)
2. [render.com](https://render.com) 가입 → GitHub 계정 연결
3. **New → Blueprint** → 저장소 선택 → **Apply**
   (`render.yaml`에 설정이 들어 있어 따로 입력할 필요 없음)
4. 배포가 끝나면 나오는 `https://gaeseon-opl-xxxx.onrender.com` 주소를 공유

Blueprint 대신 **New → Web Service**로 만들 경우: Build Command `npm install`, Start Command `node server.js`, Instance Type **Free**.

- 이후 GitHub에 push할 때마다 자동으로 다시 배포됩니다.
- 무료 플랜은 15분간 접속이 없으면 잠들고, 다음 첫 접속 때 깨어나는 데 1분 정도 걸립니다.
- 서버가 재시작되면 점수판은 초기화됩니다.

## 무기

| 무기 | 데미지 | 사거리 | 초당 발사 | 탄창 |
|---|---|---|---|---|
| 권총 (기본) | 20 | 16m | 3.3 | 12 / 무한 |
| 기관단총 | 11 | 12m | 11.8 | 30 |
| 산탄총 | 13 × 8발 | 7.5m | 1.2 | 6 |
| 돌격소총 | 22 | 22m | 8.3 | 25 |
| 저격소총 | 50 | 45m | 0.8 | 5 |
| 수류탄 | 최대 110 (반경 4.5m) | 14m | - | 3개 |

- 바닥의 무기를 밟으면 빈 칸에 자동으로 들어갑니다. 이미 있는 무기면 탄약이 보충됩니다.
- 먹은 아이템은 원래 자리가 아니라 **다른 빈 자리에 무작위로** 다시 생깁니다 (무기 15초, 체력 20초 뒤).
- 조준점을 적의 몸(발끝~머리) 위에 올리면 빨갛게 바뀌고, 그 적의 몸통을 정확히 겨눕니다.
  벽·상자·드럼통을 가리키면 가리킨 그 지점에 맞습니다 (탄퍼짐은 무기마다 있음).
- 발밑의 흰 원이 현재 무기의 사거리입니다. 상자·드럼통·벽에 막히는 방향은 원이 안쪽으로 들어가 보입니다.
  조준점이 회색이면 사거리 밖입니다.
- 죽으면 들고 있던 무기를 떨어뜨리고 3초 뒤 **맵의 무작위 위치**(1층, 건물 안, 옥상)에서 권총만 들고 부활합니다.
  적 바로 옆이나 적에게 보이는 자리는 피합니다.
- 부활 후 **5초간 무적**입니다. 그동안은 피해를 받지 않고, 자신도 총·수류탄으로 공격할 수 없습니다 (푸른 보호막).
- 수류탄 폭발은 벽·상자 뒤에 있으면 막힙니다. 자기 수류탄에도 피해를 입습니다 (60%).
- 처치/사망 수는 왼쪽 아래 HUD, 머리 위 이름표(`이름 처치/사망`), Tab 점수판에 표시됩니다.

## PvE 스테이지

접속 화면에서 **PvE 스테이지**를 고르면 같은 PvE를 고른 친구들과 한 편이 되어 진홍 군단과 싸웁니다.
지금 맵을 다섯 구역으로 나눈 스테이지이고, 구역의 적을 모두 쓰러뜨리면 다음 스테이지 시작 지점으로 이동합니다
(살아 있으면 무기 그대로 + 체력·수류탄 회복). PvP와 PvE는 서버 하나에서 따로 돌아갑니다.

| 스테이지 | 구역 | 적 |
|---|---|---|
| 1-1 들판 정찰 | 북서 들판 | 견습 병사, 보급병 |
| 1-2 관제소 점거 | 북쪽 관제소 (안팎) | + 순찰 경비병, 증원 |
| 1-3 북동 수로 | 수로, 공중 발판, 감시탑 | + 졸린 저격수, 증원 |
| 1-4 창고 돌파 | 동쪽 창고 (안팎) | 섞어서, 증원 |
| 1-5 보스전 | 중앙 광장 | **진홍의 여제 카르민** + 견습 병사 |

- 적은 모두 **느린 탄을 한 발씩** 쏘고, 쏘기 전에 총구에 빛이 모이는 **예고**가 있습니다 → 옆으로 움직이면 피할 수 있음.
  한꺼번에 공격을 준비하는 적은 2명까지라 적이 몰려도 너무 어렵지 않습니다.
  - **견습 병사**(붉은 교복): 3~4초마다 한 발
  - **순찰 경비병**(회색 군복): 두 지점을 왕복하다가 발견하면 머리 위에 **!** → 한 발. 몰래 뒤로 돌아가 먼저 쏘기
  - **졸린 저격수**(검은 교복): 옥상에서 **빨간 레이저**로 2초 겨눈 뒤 한 발, 쏘고 나면 **Zzz** 졸기 (다가갈 기회)
  - **겁쟁이 보급병**(하얀 군복): 쏘지 않고 도망침. 잡으면 체력과 무기를 꼭 떨어뜨림
- **보스 카르민**(개틀링): 패턴을 번갈아 씀
  - 기본 공격: 부채꼴 탄, 개틀링 연사, 사방으로 퍼지는 원형 탄 (모두 예고 후 발사)
  - **바닥 장판**: 발밑과 주변에 붉은 원이 깔리고 원이 다 차면 폭발 → 원 밖으로 나가면 안전
  - 체력 절반 이하에서 분노: 탄이 늘고 호위병을 부름. 쓰러뜨리면 개틀링을 떨어뜨림
- PvE에서는 권총 + **돌격소총**을 들고 시작하고, 적을 쓰러뜨리면 가끔 무기·체력 아이템을 떨어뜨립니다.
- 적은 플레이어 수에 따라 체력이 늘어납니다. 같은 편끼리는 총·수류탄 피해가 없습니다.
- 죽으면 3초 뒤 지금 스테이지 시작 지점에서 부활합니다. 1-5를 깨면 15초 뒤 1-1부터 다시 시작합니다.

## 맵 (80m x 80m)

- **건물 5채** (중앙 건물, 창고 2, 관제소 2): 문으로 들어갈 수 있고, 안에는 방·칸막이벽·상자가 있습니다.
  중앙 건물은 안쪽 계단으로 옥상 구멍까지 올라갑니다. 창고는 바깥 계단, 관제소는 점프 발판으로 옥상에 갑니다.
- **시야**
  - 둘 다 바깥이면 화면 끝까지 항상 보입니다 (상자·드럼통 뒤에 있어도 사라지지 않음).
  - 사거리 원(장애물에 막히는 시야 표시)은 건물 안이나 창문으로 들여다볼 때만 나옵니다.
  - 건물 안에 들어가면 지붕이 사라지고 안이 보이며, 바깥은 **창문·문으로 직접 보이는 곳만** 밝게 보입니다.
  - 바깥에서 **창문·문 가까이** 가면 그 건물 안이 창문으로 보이는 만큼 보입니다.
  - 건물 안에 있는 사람은 창문·문으로 직접 보이지 않으면 밖에서 보이지 않습니다.
- **부서지는 물체**: 나무 상자와 드럼통은 총·수류탄으로 부서지고 45초 뒤 다시 생깁니다.
  쌓인 상자는 아래가 부서지면 같이 무너집니다. **빨간 드럼통**(흰 불꽃 표시)은 부서지면 폭발합니다.
- **점프 기믹**
  - 끊긴 다리: 창고 옥상 ↔ 중앙 건물 옥상 다리 가운데가 끊겨 있어 뛰어 건너야 합니다 (떨어지면 1층).
  - 공중 발판: 관제소 옥상에서 감시탑까지 조금씩 높아지는 발판을 뛰어 건넙니다.
  - 점프 발판(노란 원판): 밟으면 약 4m 튀어 올라 옥상·감시탑 위로 올라갑니다.
  - 수로·연못: 물에 들어가면 느려집니다 (45%). 뛰어넘거나 징검돌·나무다리로 건너세요.
  - 울타리: 걸어서는 못 지나가고 점프로 넘습니다 (총알은 위로 지나감).
  - 감시탑: 상자를 밟고 점프로 올라가면 저격소총이 있습니다.
- 다른 층의 적은 마우스를 적 위에 올리면 높이까지 맞춰 조준됩니다. 옥상 가장자리에서는 아래를 쏠 수 있습니다.

## 파일 구성

- `server.js` — 웹 서버, 접속 관리, 인터넷 터널
- `game.js` — 게임 판정 (PvP 방 / PvE 방, 체력, 인벤토리, 아이템, 부활, 적 AI, 길찾기, 스테이지)
- `shared/common.js` — 맵, 무기 수치, 이동/충돌/사격 판정 (서버·클라이언트 공용)
- `public/client.js` — 브라우저 클라이언트 (입력, 네트워크, HUD)
- `public/pixelpass.js` — 도트 렌더링 (저해상도 + 외곽선 + 픽셀 격자 맞춤)
- `public/textures.js` — 도트 텍스처 (코드로 그림)
- `public/characters.js` — 캐릭터 그리기 (방향별 걷기 애니메이션, 벽 뒤 실루엣), 3D 총 모델(바닥 아이템)
- `public/sprites/` — 캐릭터·적·보스 걷기 시트와 얼굴 그림, `public/sheets.js` — 시트의 칸 정보 (자동 생성)
- `art/` — 원본 걷기 시트 (Grok으로 만든 그림), `tools/sheets.py` — 원본을 게임용으로 가공하는 도구
- `public/fog.js` — 건물 안 시야 가림 (창문·문으로 보이는 곳만 밝게)

무기 수치, 맵, 적 능력치(`ENEMIES`), 스테이지 구성(`STAGES`)은 `shared/common.js`에서 바로 고칠 수 있습니다.

### 캐릭터 추가하기

1. Grok 등으로 걷기 시트를 만듭니다: 초록 단색 배경, **3줄 × 6칸** (1줄 앞쪽으로 걷기, 2줄 뒷모습, 3줄 오른쪽으로 걷기).
   기존 시트(`art/haru_sheet.webp`)를 함께 첨부하면 그림체와 크기가 맞습니다.
2. `art/<이름>_sheet.webp`로 저장하고 `tools/sheets.py`의 `SOURCES`에 한 줄 추가합니다
   (프레임 중 리본이 빠진 칸 등은 `head_fix`로 다른 칸의 머리를 옮겨 붙이거나 `frames`에서 뺄 수 있음).
   색만 바꾼 적은 `VARIANTS`에 추가합니다.
3. `python tools/sheets.py` 실행 (Python, `pip install pillow numpy` 필요) → `public/sprites/`와 `public/sheets.js`가 만들어집니다.
4. `public/characters.js`의 `CHARACTERS`에 추가하고, `shared/common.js`의 `CHARACTER_COUNT`를 늘립니다.
